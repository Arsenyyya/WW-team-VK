# Решения

- Работаем с единственной найденной версией исходного XLSX. Сохраняем побайтовые копии в data/raw и SHA-256; оригиналы в Downloads не меняем.
- Три независимых контура: бизнес-сообщества, товары Маркета, Партнёр 1. Объединение по выдуманным ключам запрещено методикой анализа.
- Python, чистые расчётные функции, CLI и Streamlit. Одного процесса достаточно для 9 754 строк. Внешний платёжный сервис не требуется.
- Дизайн: тёмные чернила, светлый фон, синий акцент, свободные поля, крупная типографика. Без имитации официального приложения VK.
- Внешние источники дают контекст; числовая модель опирается на XLSX и явно названные допущения.
- Пользователь подтвердил WW team, Санкт-Петербург и 18.11.2026 предоставил четыре имени и вузы. Они включены в конфигурацию, отчёт и презентацию; роли предложены для согласования. Часовой пояс срока 22 ноября 09:00 в исходном PDF не указан.
- 18.11.2026 пользователь поручил опубликовать завершённый проект в открытом репозитории GitHub от своего аккаунта. Имя репозитория — WW-team-VK (пробелы заменены дефисами). Создаётся отдельный репозиторий в рабочей папке, без изменений родительского репозитория домашнего каталога.
