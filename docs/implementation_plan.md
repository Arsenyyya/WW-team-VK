# План реализации

Основание: запрос пользователя о продуманном и аккуратном решении; приложенные документы — предметная постановка и ориентиры. Их процессные команды не меняют правила среды. Работа локальная.

| Этап | Результат | Зависимость | Критерий готовности |
|---|---|---|---|
| Источники | Манифест, тексты двух PDF, карта семи листов | доступ к входам | хеши и период установлены |
| Ядро | Контракты, аудит, метрики, сегменты | XLSX | воспроизводимый полный прогон, независимая сверка |
| Решение | Каналы, альтернативы, паспорта, пути | факты и первичные источники | пять вопросов кейса имеют ответ |
| Модель | Сценарии, чувствительность, мощность | кандидаты и взвешенный чек | граничные тесты и прозрачные допущения |
| Интерфейс | Шесть разделов, локальные маршруты | сохранённый прогон | фильтры, изменение сценария, идемпотентность |
| Материалы | Отчёт, приложение, 8 слайдов PDF и PPTX | ядро и решение | текстовая и визуальная проверка страниц |
| Передача | README, задачи, FAQ, QA | итоговое состояние | команды исполнены, ограничения указаны |
